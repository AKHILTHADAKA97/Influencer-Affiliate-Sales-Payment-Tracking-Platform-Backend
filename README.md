# Influencer AI Platform

Demo-ready AI full-stack platform for influencer affiliate tracking, payment operations, and real-time ROI analytics.

## Stack
- Frontend: React + Vite + Chart.js + Socket.io client
- Backend: Node.js + Express + MongoDB (Atlas or local in-memory fallback)
- AI: OpenAI API for insights and fraud summaries
- Payments: Razorpay payout API + secure webhook verification

## Core capabilities
- Roles: `admin`, `influencer`, `finance` with JWT auth
- Tenant isolation by `brandId` (queries scoped to tenant)
- Affiliate tracking: click, conversion, revenue by referral code
- Commission lifecycle: `pending -> approved -> paid`
- Exports: payment reports as CSV and PDF
- Real-time dashboard updates via Socket.io
- AI features:
  - sales forecast for **7 and 30 days**
  - AI performance insights
  - fraud anomaly detection + AI summary

## Setup

### Backend
```bash
cd server
npm install
# create .env from .env.example
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

## Environment variables

### `server/.env`
- `PORT=5000`
- `MONGO_URI=<atlas_or_local_mongo_uri>`
- `JWT_SECRET=<auto-generated if empty in dev>`
- `OPENAI_API_KEY=<your_openai_key>`
- `OPENAI_MODEL=gpt-4o-mini`
- `RAZORPAY_KEY_ID=<key>`
- `RAZORPAY_KEY_SECRET=<secret>`
- `RAZORPAY_WEBHOOK_SECRET=<webhook_secret>`
- `CLIENT_URL=http://localhost:5173,http://localhost:5174`
- `COMMISSION_PERCENT=10`
- `ALLOW_MEMORY_DB_FALLBACK=true` (set `false` in production)
- `NODE_ENV=development`

### `client/.env`
- `VITE_API_URL=http://localhost:5000/api`
- `VITE_API_ROOT=http://localhost:5000`

## Production config notes
- Set `NODE_ENV=production`
- Set `ALLOW_MEMORY_DB_FALLBACK=false`
- Use only Atlas URI with working credentials
- Configure strict `CLIENT_URL` for deployed domain
- Keep secrets in deployment environment only (never in repo)

## Secure webhook endpoint
- `POST /api/payment/webhook/razorpay`
- Verifies `x-razorpay-signature` with HMAC SHA256 using `RAZORPAY_WEBHOOK_SECRET`
- Rejects invalid or tampered payloads

## API overview
- Auth: `POST /api/auth/signup`, `POST /api/auth/login`
- Influencers: `POST /api/influencer/create`, `GET /api/influencer/list`, `GET /api/influencer/me/:userId`
- Tracking: `POST /api/track/click`, `POST /api/track/sale`
- Payments: `GET /api/payment/history`, `PATCH /api/payment/approve/:id`, `POST /api/payment/process/:id`
- Exports: `GET /api/payment/export/csv`, `GET /api/payment/export/pdf`
- Analytics: `GET /api/analytics/overview`, `GET /api/analytics/ai-insights`, `GET /api/analytics/sales-prediction?days=7|30`, `GET /api/analytics/fraud-detection`, `GET /api/analytics/influencer/:influencerId`
